# Maa Ke Haton Ka Acchar 🥒

Homemade pickles made with a mother's love — Ambikapur, Chhattisgarh (PIN 497001).

**All-in-one website** for the pickle business: products, seasonal pickles, story, gallery, reviews, FAQ and contact — with WhatsApp ordering and a **9-language switcher** (English, हिन्दी, বাংলা, ଓଡ଼ିଆ, తెలుగు, मराठी, தமிழ், ગુજરાતી, ਪੰਜਾਬੀ).

## What's inside

| File | Purpose |
|---|---|
| `index.html` | The whole one-page website (structure) |
| `styles.css` | Design / look (mobile-first) |
| `script.js` | **Edit your WhatsApp number, phone, email here** |
| `products.js` | **Edit products, prices, sizes, seasonal items here** |
| `languages.js` | All website text in 9 languages (edit/fix here) |
| `manifest.json` + `sw.js` + `icons/` | Makes the site installable as an app (PWA) |
| `PUBLISH-GUIDE.md` | How to publish the site free |
| `EDIT-GUIDE.md` | How to update prices, photos, reviews, etc. |

## Live website

Once GitHub Pages is enabled (Settings → Pages → Branch: `main` → Save), the site is live free at:
`https://bs21082010.github.io/Picklepalace/`

## How customers order

Every product has an **Order on WhatsApp** button that opens WhatsApp with the order pre-typed. No fees, no payment gateway needed — works from day one.
